# Rental Studio setup

## 1. Shop settings

Open **Rental Studio → More tools → Policies & settings**.

- Enable rental shopping and select **Sale and rental** if the shop sells and rents.
- Review the shop timezone, opening hours, booking lead time, preparation and cleaning buffers.
- Set the booking advance and when the security deposit is collected.
- Enter the actual cancellation, late-return, damage, cleaning and deposit-refund terms. Add rental FAQs.
- Enable only the optional tools and reminders the shop will use. Save settings.

Prices, physical stock and business policies must come from the shop owner. A configuration check alone does not verify live payment or reminder delivery.

## 2. Publish a product

In **Product Drafts**, choose **Rent** or **Sale + rent**, review photos and product details, and publish. Sale and rental prices are independent. Adjustable fitting does not require a fixed size.

## 3. Guided setup

Use **Set up a rental product**. If the product editor already created an inactive offer, choose it in **Offer to set up** instead of creating another offer.

1. **Price & fitting:** choose the catalogue product, enter daily rent and refundable security, and select the product's advance rule. “Use shop policy” uses the shop advance. Review fitting and included items; optional fees remain separately configurable. Save price and continue.
2. **Physical pieces:** select the component and enter the rack. Count the actual new items being registered. **Generate codes & register pieces** assigns a code to each one. An existing label can be entered through **add one piece manually**. For sets, register each component separately. The entered quantity adds new pieces; it does not set a total or copy sale stock.
3. **Review & activate:** resolve the checks, then activate. Registration proves configured physical capacity, while booking dates still depend on reservations, preparation, cleaning and shop slots. Review payment and shop-opening warnings before accepting online bookings.

## 4. Daily work

- **Daily work:** pickups, returns, overdue returns, outstanding balance and refunds. Pickup and return filters use the chosen operations date; overdue/balance/refund filters cover all dates.
- **New booking:** create a counter booking for a customer, review dates and server quote, then collect the required advance.
- **Calendar:** check dates and physical-piece reservations.
- **Physical pieces:** find codes and racks, review condition, edit a piece, print labels or block maintenance dates.
- **More tools:** setup issues, packages, workshop, settlement, reports, reminders and shop policies.

For a booking: collect advance → prepare pieces → verify payment and handover → receive → inspect/clean → settle the deposit. Use **Manage** to work on that booking. Customers follow their booking in **My rentals**.
